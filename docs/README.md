## Project Lifecycle Phases

OctoAcme projects follow a structured lifecycle:

1. Initiation — Validate the business need and align stakeholders
2. Planning — Break work into shippable increments and create a roadmap
3. Execution — Build, test, review, and iterate with regular team rhythm
4. Release — Deploy to production with reduced risk and observability
5. Retrospective — Capture learnings and continuous improvements

## Brief Overview of OctoAcme Project Management Processes

- Initiation: Capture a concise one-pager (problem, objective, success metrics) and confirm stakeholder alignment and go/no-go decisions.
- Planning: Create a prioritized backlog with acceptance criteria, estimate scope, and produce a release timeline and Definition of Done.
- Execution: Operate in short increments with daily standups, small PRs, CI checks, and an enforced review process. Track progress on the project board and escalate blockers per the escalation paths.
- Release: Follow pre-release checks, automated pipelines where possible, smoke tests, and documented rollback plans.
- Retrospective & Improvement: Run timeboxed retrospectives, create prioritized action items, and track their impact.

## Core Roles (Quick Reference)

- Project Manager (PM) — coordinates delivery, schedules, risk, and communications
- Product Manager (PdM) — defines outcomes, prioritizes backlog, measures success
- Developers — implement features and collaborate on design and testability
- QA/Testing — validate quality and acceptance criteria
